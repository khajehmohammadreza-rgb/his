# ممیزی GitHub و ادغام یکپارچه

تاریخ کنترل: ۲۰ مهر ۱۴۰۵ / ۱۲ اکتبر ۲۰۲۶

## اقلام قابل مشاهده
- مخازن تحت مالکیت متصل: فقط `khajehmohammadreza-rgb/his`
- شاخه‌های قبل از ادغام: `main` و `catalog-build-v22`
- `main`: دو بسته ZIP قدیمی HIS به‌علاوه فایل‌های ریشه (بدون پوشه‌های وعده‌داده‌شده `app/` و `api/`)
- `catalog-build-v22`: ادامه تاریخچه main و چهار قلم منحصربه‌فرد: workflow، دو اسکریپت Inno Setup و ZIP سورس قدیمی
- در زمان ممیزی هیچ فایل منبع کیوسک در این مخزن پیدا نشد.

## تصمیم‌ها
1. ادغام Git باید Fast-forward باشد تا تاریخچه و SHAهای قابل بازیابی حفظ شوند.
2. ZIPهای قدیمی HIS به `archive/his/` جابه‌جا شدند، نه حذف همیشگی.
3. بسته صحیح سورس v2.2 جای بسته اولیه در `apps/catalog/source/` قرار گرفت و ۳۴ فایل آن زیر `apps/catalog/src/` استخراج و نسخه‌بندی شدند.
4. Runtime قدیمی HIS در ریشه ماند تا مسیرهای محتمل استقرار ناخواسته نشکند.
5. .env عمومی از HEAD حذف شد؛ **تاریخچه Git هنوز محتوا را نگه می‌دارد**.
6. اطلاعات بالینی، بکاپ و کلید واقعی نباید وارد Git شوند.
7. اتصال این مخزن به آخرین توسعه R24/R25 یا Kiosk تا ارائه فایل‌های مبنای مربوطه تأیید نشده است.
