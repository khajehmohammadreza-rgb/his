**تصمیم جدید:** سورس هر چهار محصول در یک مخزن مرکزی `khajehmohammadreza-rgb/his` با پوشه‌های جدا نگهداری شود؛ تفکیک پوشه برای جلوگیری از اختلال نسخه‌هاست، نه الزام به چند مخزن. هر محصول چرخه انتشار و دیتابیس مستقل دارد.

| محصول | مسیر مرکزی | وضعیت |
| --- | --- | --- |
| Bastiyan HIS | `apps/his/src/` | کد GitHub اکنون R25 است؛ بسته R37 باید منتشر و آزمایش شود. |
| Bastiyan Kiosk | `apps/kiosk/src/` | سورس متنی 3.3.20 ناقص است؛ مخزن جداگانه `kiosk` تا انتقال کامل همچنان حفظ می‌شود. |

## قواعد مرجع

- داده و حساب بیمار **در GitHub نگهداری نمی‌شوند**؛ صرفاً کد/دارایی‌های عمومی و منابع قابل ساخت.
- تغییر سورس هر محصول تنها پس از تست خودش روی شاخه جدا ادغام می‌شود.
- `main` تا رفع مغایرت نسخه‌ها **مرجع Deploy عملیاتی نیست**.
- هر محصول متغیرهای محیط، رمزها، پشتیبان‌گیری و مسیرهای پایدار جداگانه دارد.
- مخزن قدیمی `kiosk` صرفاً پس از انتقال سالم کل نسخه و ابزارهای build می‌تواند به حالت آرشیو درآید؛ فعلاً حذف نمی‌شود.
