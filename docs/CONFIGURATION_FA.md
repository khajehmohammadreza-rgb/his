# تنظیمات محیط‌های باستیان

## HIS R25
- PHP 8.4 با `pdo_sqlite`، `sqlite3` و فعال بودن قابلیت‌های ضروری برنامه.
- SQLite، فایل‌های مرکز و Snapshot/backup در دیسک پایدار خصوصی سرور؛ هرگز در Git.
- از `apps/his/src/api/config.local.example.php` فقط به‌عنوان نمونه استفاده کنید و مقادیر محیطی واقعی را در خود سرور تعریف کنید.
- کلید Chabokan AI از توکن پلتفرم/دیپلوی مستقل باشد. رمزها نباید در YAML یا سورس GitHub ثبت شوند.
- Deploy از GitHub به Production پیش‌فرض **غیرفعال** است؛ ابتدا انتشار آزمایشی و تست ترخیص.

## Kiosk 3.3.20
- پشته PHP و دارایی‌های JS، به‌همراه فایل‌های صوتی و تصویری اصل نسخه در محیط استقرار لازم‌اند.
- `chabok.json` داخل بسته نمونه است؛ شناسه سرویس و توکن‌های واقعی فقط در محیط خصوصی/Secrets سرویس مقصد.
- تست کامل نوبت‌دهی، اعلان صدا و دستیار سریع پزشک روی Windows/Chrome/Edge قبل از انتشار الزامی است.

## Catalog 2.2
- پایگاه داده SQLite روی رایانه مادر و HTTPS محلی، پورت اصلی TCP 8765 و UDP 8766 برای کشف سرور.
- `.github/workflows/catalog-native-build.yml` از سورس `apps/catalog/src/` فایل APK Debug و فایل EXE و Setup ویندوز می‌سازد.
- ساخت APK/EXE ≠ تأیید دوربین واقعی، شبکه مرکز یا امضای نهایی Release.
- از تأیید واقعی دوربین، چاپ برچسب، برق/شبکه و بازیابی بکاپ قبل از استفاده عملیاتی مطمئن شوید.

## اصول مشترک
همه محصول‌ها تحت یک مخزن هستند ولی تنظیمات، فایل‌های مرکز، کاربرها، secrets و پایگاه داده هر محصول باید **مجزا** بمانند.
