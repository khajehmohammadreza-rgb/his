# پیکربندی متمرکز Bastiyan — ۱۴۰۵/۰۷/۲۰

## HIS — نسخه معتبر 5.1.4 R24
- مسیر کد: `apps/his/src/`. این مسیر، سورس تاییدشده است و با ریشه قدیمی مخزن اشتباه نشود.
- محیط اجرایی: PHP 8.4 + افزونه‌های SQLite/PDO_SQLite.
- قالب محلی: `apps/his/src/api/config.local.example.php`. فایل اجرایی `api/config.local.php` را فقط در سرور ایجاد کنید؛ هرگز Commit نکنید.
- محل دیتابیس: persistent private volume با مجوز درست نوشتن؛ همراه با بکاپ مستقل و تست بازیابی.
- مقادیر محرمانه: `BASTIAN_SUPERADMIN_PASSWORD_HASH`، `BASTIAN_BACKUP_KEY`، `BASTIAN_DATA_ENCRYPTION_KEY`، API کاوه‌نگار و Gemini فقط در محیط امن.
- کلید AI چابکان و کلید مدیریت پلتفرم چابکان دو اعتبار مستقل هستند؛ آن‌ها را جای یکدیگر استفاده نکنید.
- اجزای فایل `update-manifest.json` و `checksum.sha256` در R24 مربوط به بسته اصلی‌اند؛ چون فونت‌های اختصاصی از مخزن عمومی حذف و قالب تنظیمات اصلاح شده، **برای نصب مستقیم به عنوان بسته آپدیت معتبر نیستند**.
- قبل از انتشار: تهیه نسخه پشتیبان واقعی → ساخت بسته با Manifest و SHA جدید → آزمون Stage → بررسی SQLite، ثبت بیمار و ترخیص → فعال‌سازی Production با امکان Rollback.
- هیچ Deploy Hook یا دسترسی به سرور عملیاتی در GitHub Actions فعال نیست.

- پروژه اندروید، کلاینت و سرور: `apps/catalog/src/`.
- ساخت‌های GitHub Actions: `.github/workflows/catalog-native-build.yml`.
- سرور HTTPS پیش‌فرض: TCP 8765. کشف LAN: UDP 8766. واسط محلی کلاینت ویندوز: 8775.
- گواهی TLS خصوصی و دیتابیس SQLite سرور روی همان رایانه مادر می‌مانند؛ در GitHub نباشند.
- اتصال اولیه گواهی مبتنی بر Trust-on-First-Use فقط روی شبکه محلی مورد اعتماد انجام شود.

- کیفیت عملی بارکدخوان تنها با دوربین دستگاه واقعی و نمونه بارکدهای محیط مرکز تأیید می‌شود.

فایل کامل `Bastiyan-Kiosk-3.3.19-READABILITY-TYPOGRAPHY-SAFE.zip` در محیط قابل‌دسترسی این مرحله نیست؛ لذا سورس یا تنظیمات نامعتبر وارد مخزن نکردم. سناریوی صف و فراخوان، کلاینت‌های ویندوز و انتشار امن بعد از ورود نسخه واقعی تست خواهند شد.

## وضعیت امنیت مخزن عمومی
- Runtime data، اطلاعات بیماران، فایل‌های آپلودی، توکن‌ها، کلیدهای خصوصی و بکاپ در GitHub ذخیره نمی‌شوند.
- فایل `.env` قدیمی حاوی `SESSION_SECRET` زمانی در تاریخچه عمومی وجود داشته است. تغییر رمز در سرور واقعی ضروری است؛ حذف از Head به‌معنای حذف از تاریخچه نیست.
- قلم‌های باینری B Titr و B Nazanin به مخزن عمومی انتقال داده نشده‌اند؛ نصب خصوصی و قانونی آن‌ها بر عهده محیط اجراست.
