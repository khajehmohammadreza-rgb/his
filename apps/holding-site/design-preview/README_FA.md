# هلدینگ باستیان — پیش‌نمایش سایت
این فایل یک طرح مستقل و ایستا بر اساس تصویر مرجع کاربر است؛ سایت عملیاتی، سامانه رزرو، فرم تماس یا اتصال خدمات نیست. لینک‌ها تنها در همان صفحه جابه‌جا می‌شوند.
برای تبدیل به سایت واقعی، باید سورس وب‌سایت و محتوای قطعی تهیه و تست شود. هیچ اتصال یا پایگاه‌داده‌ای در این پیش‌نمایش وجود ندارد.
