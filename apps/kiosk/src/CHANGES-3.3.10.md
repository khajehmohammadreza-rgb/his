# Bastiyan Kiosk 3.3.10 — Doctor Flow / UI Dedup / Safe Deploy

## پنل پزشک
- در همان کارت بیمار در حال ویزیت، دو اقدام اصلی و واضح اضافه شد:
  - **فراخوان بیمار بعد**: ویزیت جاری را پایان می‌دهد و اولین نوبت فعال بعدی را بلافاصله فراخوان می‌کند.
  - **پایان ویزیت**: فقط ویزیت جاری را خاتمه می‌دهد.
- عملیات «فراخوان بیمار بعد» در Backend به شکل اتمیک پیاده‌سازی شده تا با دوبار کلیک، بیمار بعدی رد نشود.
- نوبت‌های غیرفعالِ ایجادشده از مسیر مدیریت لیست، در انتخاب بیمار بعدی نادیده گرفته می‌شوند تا پزشک قبل از فعال‌سازی توسط منشی نتواند آن‌ها را فراخوان کند.

## حذف امکانات تکراری
- بخش قدیمی «دانلود راه‌اندازها و میانبرهای دسکتاپ» از رابط مدیریت حذف/غیرفعال شد.
- مسیر رسمی دریافت پنل‌ها فقط بخش جدید **پنل‌های ویندوز Native** است.
- ویرایشگر قدیمی «زیرنویس و پیام‌های روان سالن» از رابط عمومی حذف/غیرفعال شد.
- مدیریت رسمی زیرنویس فقط از **تنظیمات نمایشگر → زیرنویس نمایشگر** انجام می‌شود.
- حذف از UI به شکل سازگار با React انجام شده تا رندر مجدد باعث برگشت بخش‌های قدیمی یا خطای رابط نشود.

## دیپلوی امن چابکان
- محتوای زنده پوشه `data/` و فایل امضای پنل‌های نصب‌شده (`data/.client_package_secret`) از Build/Deploy جدید کنار گذاشته شده‌اند.
- بسته آپدیت داخلی از قبل هر فایل داخل `data/` را رد می‌کند و هنگام نصب نیز آن را جایگزین نمی‌کند.
- بنابراین URL امضاشده پنل‌های نصب‌شده پزشک/منشی/نمایشگر ثابت می‌ماند و پس از ارتقای کد سرور، نیازی به نصب مجدد پنل‌ها نیست.
- شرط مهم: دامنه/آدرس اصلی سرور و Persistent Storage پوشه `data/` در چابکان باید حفظ شوند.

## نسخه

- Windows installed launcher architecture: سازگار با بسته‌های 3.3.9 و بدون الزام نصب مجدد.
