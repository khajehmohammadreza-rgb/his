# Bastiyan Kiosk 3.3.9 - Windows Native Installer

- رفع خطای دانلود پنل‌ها ناشی از نبود Setup.exe از پیش Build شده.
- جایگزینی کامل مسیر Electron/NSIS ناقص با نصاب Native ویندوز x64 ساخته‌شده با Go.
- چهار دانلود مجزا برای پزشک، منشی، نمایشگر و سوپرادمین با client.json اختصاصی همان مرکز و نقش.
- نصب در LocalAppData بدون نیاز به PowerShell/VBS/.NET/Node/PHP/Python/Java.
- ایجاد Shortcut واقعی Windows روی Desktop و Start Menu با آیکن Bastiyan.
- اجرای پنل در Microsoft Edge App Mode با Profile مستقل برای هر نقش/مرکز.
- در پنل پزشک و منشی، انتخاب نام فارسی روش اصلی ورود است؛ Username انگلیسی به بخش جایگزین منتقل شد.
- حفظ اعتبارسنجی سمت سرور؛ انتخاب نام فارسی به همان userId واقعی و سطح دسترسی واقعی متصل می‌شود.
