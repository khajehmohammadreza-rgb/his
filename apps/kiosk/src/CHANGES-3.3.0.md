# Bastiyan Kiosk 3.3.0 — Commercial Role Installers

- بازطراحی کامل بخش «نسخه‌های نصب‌شونده ویندوز» برای هر مرکز.
- چهار بسته مستقل: پزشک، منشی، نمایشگر و سوپرادمین.
- هر بسته با HMAC به همان مرکز + همان نقش قفل می‌شود و اعتبارسنجی سمت سرور دارد.
- نسخه پزشک: فهرست کشویی پزشکان فعال همان مرکز + فقط رمز عبور؛ هیچ نام کاربری لازم نیست.
- نسخه منشی: فهرست کشویی منشی‌های فعال همان مرکز + فقط رمز عبور.
- نسخه نمایشگر: مرکز از قبل قفل شده و فقط رمز نمایشگر درخواست می‌شود.
- نسخه سوپرادمین: ورود فقط حساب سوپرادمین و دسترسی کامل به همه پنل‌ها.
- نصب ویندوز با رابط گرافیکی PowerShell، آیکن Bastiyan روی Desktop و Start Menu، ثبت در Apps & Features و Uninstaller.
- هر نسخه با مرورگر App Mode و user-data-dir مستقل اجرا می‌شود تا نشست نقش‌ها با یکدیگر تداخل نداشته باشد.
- اضافه‌شدن میانبر «نسخه‌های نصب» روی کارت هر مرکز در صفحه مدیریت مراکز.
- افزودن پنل حرفه‌ای چهارکارتی دانلود داخل تنظیمات مرکز، مستقل از React اصلی.
