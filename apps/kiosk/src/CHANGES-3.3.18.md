# Bastiyan Kiosk 3.3.18 — Final Secretary Table UI Safe

این نسخه مستقیماً بر پایه 3.3.17 ساخته شده و فقط تجربه کاربری ثبت نوبت در پنل منشی را بازطراحی می‌کند.

## بازطراحی پنل منشی
- حذف کامل ناحیه بالایی «انتخاب بازه / شماره‌های پراکنده / عملیات گروهی».
- انتقال «اعمال نوبت‌های انتخاب‌شده» به پایین همان جدول نوبت‌ها.
- ترکیب تیک انتخاب و شماره نوبت در یک سلول و قرارگیری عملیات ثبت بلافاصله کنار آن برای کاهش خطای ردیف.
- افزودن «انتخاب همه» در سرستون جدول برای انتخاب یکجای تمام شماره‌های آزاد.
- هر نوبت آزاد به‌صورت پیش‌فرض «فعال برای فراخوان» است؛ منشی در صورت نیاز می‌تواند تیک فعال همان ردیف را بردارد یا انتخاب‌های فعلی را گروهی غیرفعال کند.
- ثبت تکی و «ثبت و چاپ» حفظ شده‌اند.
- چاپ و پیش‌نمایش نوبت‌های ثبت‌شده حفظ شده‌اند.
- یادداشت محرمانه پزشک و ویرایش/لغو از فهرست پایین صفحه بدون تغییر باقی مانده‌اند.
- شمارنده و شماره‌های انتخاب‌شده در نوار پایین جدول دیده می‌شوند.
- Backend صف، API، چاپ، فراخوان منشی، TV و Windows Runtime تغییر نکرده‌اند.

## ایمنی انتشار
- پوشه data در Release وجود ندارد.
- هیچ Migration جدیدی وجود ندارد.
- پنل‌های Windows نصب‌شده نیاز به نصب مجدد ندارند.
