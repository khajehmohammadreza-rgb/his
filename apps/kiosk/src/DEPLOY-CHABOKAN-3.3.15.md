# دیپلوی امن Bastiyan Kiosk 3.3.15 روی چابکان

این نسخه یک انتشار UI برای پنل منشی است و هیچ Migration داده‌ای ندارد.

## قبل از دیپلوی
- از پوشه `data/` فعلی بکاپ بگیرید.
- `data/.client_package_secret` را حذف یا جایگزین نکنید.
- فایل‌های `clinic_store.json`، `users_store.json` و `sessions_store.json` باید Persistent بمانند.

## دیپلوی
- محتوای این بسته را مانند نسخه‌های Safe Deploy قبلی روی برنامه جایگزین کنید.
- پوشه `data/` از این بسته ارسال نشده و نباید از روی نسخه قبلی حذف شود.
- دامنه/URL اصلی سامانه را تغییر ندهید تا پنل‌های نصب‌شده Windows همان اتصال قبلی را حفظ کنند.

## بعد از دیپلوی
- پنل منشی را یک بار بسته و مجدداً باز کنید یا Refresh کامل انجام دهید.
- نصب مجدد پنل‌های Windows لازم نیست.
- پزشک را انتخاب و ثبت تکی، ثبت گروهی، فعال/غیرفعال، یادداشت و چاپ را با یک نوبت آزمایشی کنترل کنید.

## نکته
`api.php` در 3.3.15 نسبت به 3.3.14 تغییر نکرده است؛ این انتشار منطق Backend صف را تغییر نمی‌دهد.
