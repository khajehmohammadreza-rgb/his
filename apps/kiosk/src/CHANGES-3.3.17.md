# Bastiyan Kiosk 3.3.17 — Final Network Resilience Safe

این نسخه مستقیماً بر پایه 3.3.16 ساخته شده و فقط مسیر ارتباط شبکه/API را مقاوم‌سازی می‌کند.

## رفع خطای اسکرین‌شات
- خطای خام Firefox با متن `NetworkError when attempting to fetch resource` دیگر مستقیماً به کاربر نمایش داده نمی‌شود.
- درخواست‌های GET/HEAD داخلی API در خطاهای موقت شبکه یا 502/503/504 تا دو بار به‌صورت خودکار و کوتاه retry می‌شوند.
- در صورت اشکال Rewrite مسیر `/api/...`، برای درخواست‌های خواندنی یک fallback امن به `/api.php?route=...` وجود دارد.
- درخواست‌های POST/عملیاتی عمداً خودکار retry نمی‌شوند تا ثبت نوبت، فراخوان یا عملیات دیگر دوبار انجام نشود.
- تزریق Authorization فقط به API هم‌دامنه انجام می‌شود؛ درخواست‌های خارجی دیگر با Header داخلی سامانه آلوده نمی‌شوند و CORS/NetworkError ناشی از آن ایجاد نمی‌شود.
- در قطع واقعی شبکه، پیام فارسی و مشخص نمایش داده می‌شود و داده‌های موجود دست‌کاری نمی‌شوند.
