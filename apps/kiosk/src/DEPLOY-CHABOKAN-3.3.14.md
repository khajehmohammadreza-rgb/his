# استقرار امن Bastiyan Kiosk 3.3.14 روی چابکان

این نسخه Migration داده‌ای ندارد و برای قابلیت ثبت گروهی نوبت، فقط کد وب/API و asset پنل منشی به‌روزرسانی می‌شوند.

1. قبل از Deploy از Volume پایدار `data/` و به‌ویژه `clinic_store.json`، `users_store.json`، `sessions_store.json` و `.client_package_secret` بکاپ بگیرید.
2. پوشه `data/`، `config.php` و فایل‌های Persistent را جایگزین یا حذف نکنید.
3. کد 3.3.14 را روی 3.3.13 منتشر کنید.
4. فایل `windows-runtime/Bastiyan-Windows-Installer-x64.exe` تغییر نکرده است؛ پنل‌های نصب‌شده پزشک، منشی و نمایشگر نیاز به نصب مجدد ندارند.
5. پنل منشی نصب‌شده را یک بار ببندید و باز کنید تا asset جدید `secretary-workspace-3.3.14.js` با Cache Buster جدید دریافت شود.
6. تست کوتاه پس از Deploy: ظرفیت حداقل ۱۲ → انتخاب بازه ۱ تا ۱۰ → پاک‌کردن انتخاب → انتخاب دستی ۱، ۶، ۱۰، ۱۱ → فعال‌کردن گروهی → اعمال نوبت‌ها → مشاهده چهار نوبت در فهرست پایین → لغو یکی از آن‌ها و اطمینان از آزادشدن شماره.

هیچ فایل `data/` در ZIP انتشار 3.3.14 قرار داده نشده است و هیچ Migration اجباری برای Queueهای قبلی وجود ندارد.
