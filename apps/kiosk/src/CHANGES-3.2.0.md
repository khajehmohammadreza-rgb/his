# Bastiyan Kiosk 3.2.0

- دو نوع نمایشگر مستقل برای هر مرکز: صف/پزشکان (مدل قبلی) و چندرسانه‌ای + صف.
- انتخاب نوع نمایشگر از تنظیمات همان مرکز.
- کتابخانه رسانه مستقل هر مرکز با ترتیب پخش، فعال/غیرفعال و مدت نمایش.
- پشتیبانی از تصویر، ویدئو، صدا، PDF و فایل ارائه.
- پشتیبانی واقعی HTTP Range برای پخش پایدارتر ویدئو و صدا.
- کاهش صدای رسانه هنگام فراخوان و بازگشت خودکار صدا.
- حذف رسانه هم فایل را حذف می‌کند و هم Playlist ذخیره‌شده همان مرکز را پاک‌سازی می‌کند.
