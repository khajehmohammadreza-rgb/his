# Bastiyan Kiosk 3.3.4 — Queue Audio & Secretary Registration Fix

## فراخوان و نمایشگر صف
- فراخوان بیمار از پنل اصلی فقط یک بار و از مسیر اتمیک `queues/call` به سرور ارسال می‌شود؛ ارسال موازی قدیمی `announcements/broadcast` حذف شد.
- Announcement Bus در سمت سرور بر اساس `callId` ضدتکرار شد؛ فراخوان تکراری دیگر صف صوتی را مسدود نمی‌کند.
- پاسخ `sync/poll` حتی وقتی نسخه داده تغییر نکرده باشد، اعلان فعال را برمی‌گرداند تا نمایشگر اعلان از دست‌رفته را بازیابی کند.
- نمایشگر هر ۸ ثانیه Full State Recovery دارد تا صف/وضعیت پزشک/نوع نمایشگر از سرور دوباره تأیید شود.
- پس از پایان اعلان، مورد بعدی صف مرکزی فراخوان فوراً Promote و پخش می‌شود.

## صدای رسانه هنگام اعلان
- در شروع فراخوان، صدای ویدئو/فایل صوتی رسانه‌ای به‌صورت کامل Mute می‌شود (نه فقط کم‌شدن صدا).
- اگر هنگام فراخوان رسانه بعدی شروع شود، آن رسانه نیز از ابتدا بی‌صدا اجرا می‌شود.
- پس از پایان واقعی اعلان و تأیید سرور، صدای رسانه با Volume تنظیم‌شده مرکز خودکار برمی‌گردد.
- نسخه Windows Display با Autoplay Policy اختصاصی اجرا می‌شود تا پخش صوت فراخوان بدون کلیک اضافه پایدارتر باشد.

## موتور صوت فراخوان
- فایل‌های Room Audio ناسازگار که با پسوند MP3 ولی Codec دیگری داشتند، به MP3 واقعی تبدیل شدند.
- برای شماره/اتاق خارج از محدوده فایل‌های صوتی موجود، Persian Web Speech به‌عنوان Fallback اضافه شد.

## ثبت بیمار منشی
- انتخاب پزشک پیش‌فرض پس از بارگذاری Async اصلاح شد؛ نمایش اولین پزشک دیگر با مقدار داخلی خالی همراه نیست.
- «ثبت و چاپ فیش» و «فقط ثبت نوبت» از پزشک Resolve‌شده استفاده می‌کنند و در صورت نبود پزشک پیام واضح می‌دهند.
- ثبت بیمار Server-authoritative شد: تا API ثبت را تأیید نکند بیمار به لیست محلی اضافه نمی‌شود.
- خطای API دیگر نادیده گرفته نمی‌شود و به منشی نمایش داده می‌شود.
- ثبت بیمار بدون نام همچنان مجاز است و با عنوان «بدون نام» ثبت می‌شود.
