# Bastiyan Kiosk 3.3.20 — Doctor Quick Hotkeys

بر پایه نسخه مرجع 3.3.19 (خوانایی).

- دو میانبر سراسری ویندوز `F8` و `Ctrl+F8`، هر دو برای نمایش/مخفی‌کردن دستیار پزشک؛ بدون فراخوان مستقیم با فشردن کلید.
- پنجره پزشک با حالت همیشه‌رو و اندازه کوچک در Edge/Chrome، بدون نیاز به تعویض تب سامانه بیمه.
- صفحه `doctor-assistant.html` با API واقعی `auth/me`, `state`, `queues/next`, `queues/call` و `queues/status` و فیلتر سمت سرور نقش پزشک.
- محافظت از فرمان‌های تکراری، بررسی شناسه نشست پزشک، خطا و قطع ارتباط، تأیید پایان ویزیت.
- تغییر محدود در لانچر ویندوز: اجرای خودکار دستیار پس از اجرای نصب‌شده، جلوگیری از اجرای دوباره، اشتراک پروفایل مرورگر.
- تغییر محدود در راهنمای ورود پزشک و تولیدکننده بسته نصب؛ بدون تغییر API یا منطق صف، نمایشگر، منشی، چاپ.
- نصب بروزرسانی Runtime ضروری است؛ *صرف انتشار صفحه وب کافی نیست*.
- ویندوز واقعی / اجرای درمانگاهی هنوز باید آزموده شود؛ هیچ استقرار زنده‌ای انجام نشده است.
