# گزارش آزمون نسخه 3.3.20 — دستیار میانبر پزشک

مبنای واقعی: `Bastiyan-Kiosk-3.3.19-READABILITY-TYPOGRAPHY-SAFE(1).zip` که در کتابخانه کاربر موجود بود.

## انجام‌شده و موفق

- ساخت خروجی بومی **Windows x64 GUI PE32+** با Go 1.23 و ابزار cross-build.
- بررسی ایستای `go vet` برای پروژه Windows launcher.
- بررسی صحت دستوری `client.php` و `download.php` با PHP lint.
- بررسی صحت دستوری فایل جدید JavaScript با Node `--check`.
- آزمون منطقی خودکار JavaScript: بازیابی صف مخصوص پزشک، تفکیک بیمار پزشک دیگر، نمایش نوبت جاری و تعداد منتظر، فراخوان بعدی، تکرار فراخوان، پایان ویزیت، مسیر و بدنه درخواست‌ها.
- بررسی اینکه API اصلی، پنل منشی، منطق صف، نمایشگر، کد اصلی UI و بخش شبکه نسخه 3.3.19 دست‌نخورده و از نظر SHA-256 عین مرجع‌اند.
- بررسی hash SHA-256 خود فایل اجرای Windows و تطابق با `windows-runtime/version.json`.
- دو میانبر `F8` و `Ctrl+F8` در کد Win32 با `RegisterHotKey` افزوده شده‌اند؛ هیچ‌کدام به‌تنهایی API فراخوان را اجرا نمی‌کنند.

## نیازمند تأیید عملی روی Windows واقعی

- دریافت واقعی `WM_HOTKEY` از سیستم‌عامل هنگام کار در Edge/Chrome/Firefox، به‌ویژه در نرم‌افزارهای بیمه و نسخه‌نویسی.
- رفتار `Always-on-top` و روشن/مخفی‌شدن پنجره در Windows 10/11، چند نمایشگر، DPIهای متفاوت و مدیریت تمرکز (Focus).
- سازگاری با سیاست آنتی‌ویروس، Windows SmartScreen، محدودیت‌های سازمانی و تداخل میانبرهای دیگر.
- تأیید عملیات فراخوان تا پخش اعلان صوتی روی نمایشگر واقعی مرکز و جلوگیری از تداخل درخواست‌های هم‌زمان در محیط درمانگاهی.
- صحت به‌روزرسانی Native از نسخه نصب‌شده روی رایانه‌های کاربر؛ روی سیستم‌های کاربران هیچ تست یا نصب راه دور انجام نشده است.

## محدودیت محیط آزمایش

در این محیط لینوکسی امکان اجرای فایل `.exe` ویندوز وجود نداشت و اجرای Chromium برای آزمون مرورگری با سیاست محیط `ERR_BLOCKED_BY_ADMINISTRATOR` مسدود شد. **آزمون واقعی ویندوز یا استقرار چابکان انجام نشده است.** آزمون منطقی JS با داده‌های تست فقط برای مسیرهای عملیاتی صفحه انجام شد و جزو دیتای محصول یا محیط تولید نیست.

## تغییرات موجود در بسته

تغییر در فایل‌های موجود فقط: `client.php`، `download.php`، `windows-native-installer/main.go`، `windows-runtime/Bastiyan-Windows-Installer-x64.exe`، `windows-runtime/README.md` و `windows-runtime/version.json`.

فایل‌های افزوده‌شده: `windows-native-installer/assistant.go`، `doctor-assistant.html`، `assets/doctor-assistant-3.3.20.js`، راهنماها و گزارش‌های انتشار.

## روش استفاده بعد از استقرار آزمایشی

1. نسخه سرور 3.3.20 را پس از پشتیبان‌گیری مستقر کنید؛ **پوشه داده مرکز را بازنویسی نکنید**.
2. نصاب نقش پزشک را اجرا کنید یا بگذارید راه‌انداز نسخه 3.3.12 به بعد، با HTTPS و SHA-256، Runtime جدید را دریافت کند.
3. یک پزشک تست وارد شود، `F8` یا `Ctrl+F8` را فشار دهد و پنل سریع را باز/مخفی کند.
4. دکمه‌های فراخوان، تکرار و پایان ویزیت را روی صف تست بررسی کند. میانبر به‌تنهایی هیچ فرمان بالینی صادر نمی‌کند.
5. صحت عملکرد نمایشگر، صدا، منشی و سایر برنامه‌های باز روی ویندوز را بررسی کنید؛ پس از تأیید به مراکز دیگر تعمیم دهید.
