# Bastiyan Kiosk 3.3.7

- نمایشگر: وضعیت بسته بودن نوبت‌دهی هر پزشک به‌صورت Badge قرمز «نوبت‌دهی امروز بسته است» روی کارت همان پزشک و در نوار وضعیت نمایش داده می‌شود؛ حتی اگر پزشک هنوز بیمار در حال فراخوان داشته باشد Badge باقی می‌ماند.
- ثبت نوبت: دو مسیر به‌صورت صریح تفکیک شدند. ثبت سریع (`ثبت` / `ثبت و چاپ`) نوبت را با `registrationSource=quick` و `isActive=true` ایجاد می‌کند. مدیریت لیست نوبت‌ها، اسلات‌های جدید را پیش‌فرض غیرفعال نگه می‌دارد و فقط پس از تیک منشی، نوبت با `registrationSource=managed-list` فعال و قابل فراخوان می‌شود.
- فراخوان پزشک: محافظ API قبلی برای جلوگیری از فراخوان نوبت غیرفعال حفظ و با منطق جدید هم‌راستا شد.
- اعلان صوتی: موتور صوتی مشترک برنامه خارج از مسیر/نقش Display غیرفعال شد؛ پنل پزشک و منشی دیگر اعلان صوتی شماره را پخش نمی‌کنند. پخش اصلی در پنل نمایشگر باقی می‌ماند.
- زیرنویس: ویرایشگر قدیمی «زیرنویس و پیام‌های روان سالن» از تنظیمات عمومی پنهان و از مسیر کاربری حذف شد؛ مدیریت زیرنویس فقط از تنظیمات نمایشگر انجام می‌شود.
- زیرنویس نمایشگر: ساختار حرکت به دو گروه کاملاً یکسان تغییر کرد تا پس از پایان متن، نسخه دوم بدون مکث وارد شود و حلقه حرکت تا حد ممکن نامحسوس باشد. زمان حرکت همچنان از `displaySettings.tickerSpeed` کنترل می‌شود.
- نسخه برنامه به 3.3.7 ارتقا یافت.

## نکته نصب Windows
در این بسته، تغییرات عملکردی بالا نهایی شده‌اند. مهاجرت Installer قدیمی مبتنی بر PowerShell/VBS به Setup.exe کاملاً Self-contained نیازمند قراردادن Runtime ویندوز/Chromium داخل بسته و ساخت/تست باینری Windows است؛ این بخش در محیط Linux حاضر به‌صورت قابل اتکا قابل اجرای نهایی نیست و بنابراین در این نسخه به‌دروغ «تکمیل‌شده» اعلام نشده است.
