# گزارش توسعه Bastiyan Kiosk 3.3.6

## تغییرات اصلی
- یکپارچه‌سازی تجربه کاربری «تیکر / زیرنویس / پیام روان سالن» با عنوان واحد «زیرنویس نمایشگر» و نگه‌داشت یک منبع داده مشترک.
- حفظ تنظیم زمان پیمایش زیرنویس و بهبود رندر تلویزیون با تکرار چندنسخه‌ای متن برای کاهش محسوس نقطه شروع/پایان حرکت.
- اصلاح منطق نگه‌داری لوگو: ارسال دوباره URL داخلی لوگو دیگر فایل موجود را حذف نمی‌کند؛ ورودی نامعتبر نیز لوگوی سالم را از بین نمی‌برد.
- محدود کردن QR فیش به یک QR و استفاده از اولین QR فعال تنظیمات نمایشگر به‌عنوان منبع واحد.
- ورود نسخه‌های نصب پزشک/منشی با Username انگلیسی یا انتخاب نام فارسی؛ اعتبارسنجی نهایی همچنان سمت سرور و Role-bound است.
- اضافه‌شدن راهنمای خوش‌آمد یک‌باره برای نحوه ورود و توضیح امنیت رمز.
- بهبود ظرفیت روزانه پزشک در پنل منشی؛ اسلات‌های غیرفعال، فعال‌سازی با تیک و ذخیره فوری وضعیت در صف.
- اضافه‌شدن کنترل پایان/بازگشایی نوبت‌دهی هر پزشک در پنل منشی؛ نمایشگر نیز وضعیت پایان نوبت‌دهی را نمایش می‌دهد و این وضعیت مانع اصلاح مدیریتی منشی نمی‌شود.
- نام‌گذاری حرفه‌ای‌تر بسته‌های ویندوز برای پنل پزشک و منشی.

## آزمون‌های انجام‌شده
- PHP lint: `api.php`, `client.php`, `download.php` بدون خطا.
- JavaScript syntax check: فایل enhancements و professional بدون خطا.
- استخراج و syntax check اسکریپت inline `tv.html` بدون خطا.
- JSON validation: `manifest.json`, `chabok.json` معتبر.
- تولید واقعی ZIP نصب پزشک و منشی با نقش و مرکز نمونه؛ `unzip -t` هر دو بسته بدون خطا.
- بررسی `client.json` تولیدشده: نسخه 3.3.6، role صحیح، centerId صحیح و نام برنامه جدید صحیح.

## محدودیت آزمون
اجرای GUI واقعی PowerShell/VBS فقط روی Windows قابل آزمون انتهابه‌انتها است. ساخت و محتوای بسته نصب در این محیط بررسی شده، اما کلیک واقعی Installer روی Windows در این محیط Linux قابل اجرا نیست.
