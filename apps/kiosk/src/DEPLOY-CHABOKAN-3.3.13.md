# استقرار امن Bastiyan Kiosk 3.3.13 روی چابکان

این نسخه Migration دیتابیس/JSON ندارد و برای حفظ پنل‌های نصب‌شده، Windows Runtime را تغییر نمی‌دهد.

1. قبل از Deploy از Volume پایدار `data/` و به‌ویژه `clinic_store.json`، `users_store.json`، `sessions_store.json` و `.client_package_secret` بکاپ بگیرید.
2. پوشه `data/`، `config.php` و فایل‌های Persistent را جایگزین یا حذف نکنید.
3. کد نسخه 3.3.13 را روی نسخه 3.3.12 منتشر کنید. فایل `windows-runtime/Bastiyan-Windows-Installer-x64.exe` همان باینری نسخه مبنا است و نیازی به نصب مجدد پنل پزشک/منشی/نمایشگر وجود ندارد.
4. پس از Deploy، یک بار پنل منشی نصب‌شده را ببندید و باز کنید تا HTML و asset با query version جدید 3.3.13 دریافت شود.
5. سناریوی پذیرش پیشنهادی برای کنترل نهایی: ظرفیت ۵ → ثبت نوبت ۲ به‌صورت غیرفعال → اطمینان از عدم فراخوان توسط پزشک → فعال‌کردن نوبت ۲ از فهرست پایین → فراخوان → لغو یک نوبت دیگر و مشاهده آزادشدن شماره در جدول بالا.

هیچ فایل `data/` در ZIP انتشار 3.3.13 قرار داده نشده است.
