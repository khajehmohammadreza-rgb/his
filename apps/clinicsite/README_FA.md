# ClinicSite / ClinicStudio

این پوشه برای تجمیع سورس سایت کلینیک در مخزن مرکزی باستیان ایجاد شده است.

**توجه: سورس قابل Deploy سایت هنوز به GitHub منتقل نشده است.** تا دریافت و تطبیق آخرین بسته معتبر ClinicStudio و اجرای آزمون‌های PHP، هیچ وضعیت «آماده نصب» برای این پوشه ادعا نمی‌شود.

هنگام انتقال، مسیرهای کد، رسانه عمومی و آزمون‌ها در همین پوشه ثبت می‌شوند. اطلاعات واقعی کاربران، رزروها، رمزها، کلید کاوه‌نگار، اطلاعات پرداخت و دیتابیس نباید Commit شوند. داده‌ها در فضای پایدار چابکان و بکاپ‌های رمزگذاری‌شده نگهداری می‌شوند.
