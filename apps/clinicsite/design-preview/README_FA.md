# ClinicStudio — پیش‌نمایش هویت بصری باستیان

این صفحه بر اساس **پیش‌نمایش واقعی ClinicStudio 2.0.2 R3 موجود در کتابخانه کاربر** ساخته شده است. تنها استایل هماهنگ با طرح مرجع اضافه شده و محتوای اصلی خدمات، پزشک، مسیرهای تماس و سازوکار منوی موجود حفظ شده‌اند.

- `index.html`: پیش‌نمایش اصلی با اسناد/خدمات قبلی (**سامانه عملیاتی نیست**)
- `bastiyan-visual-2026.css`: پوسته سفید/سرمه‌ای/فیروزه‌ای قابل بازگشت
- `assets/bastiyan-architecture.svg`: تصویر تزئینی وکتور بدون بارگذاری خارجی

**انتشار نکنید:** رزرو نوبت، ورود بیمار، OTP، پیامک و پرداخت هنوز به سورس PHP اصلی سایت نیاز دارند؛ این فایل، جایگزین ClinicStudio روی سرور چابکان نیست. از قرار دادن پایگاه داده و کلید API در GitHub خودداری شود.
