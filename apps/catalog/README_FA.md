# Bastiyan Catalog Collector v2.2

کد جمع‌آوری بارکد و کالا با پوشه‌بندی زیر:
- `source/v2.2-production-sources.zip`: آرشیو کامل سورس نسخه ۲.۲ (Android + Windows + Python)
- `installers/`: فایل‌های تولید Setup.exe ویندوز
- `src/`: در ادامه باید سورس استخراج‌شده از ZIP و قابل تغییر در Git قرار بگیرد
- `.github/workflows/catalog-native-build.yml`: دستور ساخت APK اندروید و نصب‌کننده‌های ویندوز

نکته: فایل APK منتشرشده قبلی با امضای Debug ساخته شده است؛ برای انتشار تجاری امضای Release نیاز است.
