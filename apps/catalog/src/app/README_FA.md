# گردآورنده باستیان ۲.۱

در ویندوز، برای اجرای مادر روی `01-سرور-مرکز.bat` و برای اجرای کلاینت روی `02-کلاینت-ویندوز.bat` کلیک کنید. پنجره مدیریت و جستجوی خودکار سرور باز می‌شود. پیش‌نیازهای گمشده روی ویندوز از اینترنت نصب می‌شوند؛ دسترسی شبکه و تأیید Firewall/UAC طبق قوانین سیستم‌عامل ممکن است لازم باشد. برای دو میان‌بر دسکتاپ `03-ساخت-آیکن-دسکتاپ.bat` را اجرا کنید.

دیتابیس با مسیر `%LOCALAPPDATA%\Bastiyan Catalog\data\catalog.sqlite3` جدا از برنامه نگهداری می‌شود. اگر نسخه ۲ دارای بانک داده در همین پوشه برنامه (`data/catalog.sqlite3`) باشد، راه‌انداز آن را با API پشتیبان SQLite به محل جدید کپی می‌کند؛ اصل فایل محفوظ می‌ماند. برای سایر مسیرهای قبلی قبل از جایگزینی بکاپ تهیه و پوشه `data` را در کنار برنامه جدید قرار دهید.

فایل کامل راهنما `../README_FA.md` و پروژه برنامه بومی اندروید در `../android-app` موجود است. **در این بسته EXE و APK کامپایل‌شده وجود ندارد.**
