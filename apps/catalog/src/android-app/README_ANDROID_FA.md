# برنامه اندروید گردآورنده باستیان — سورس نسخه ۲.۱

این پوشه **سورس کامل پروژه Native Android** است و به‌تنهایی APK محسوب نمی‌شود. برای تولید APK، Gradle 8.10.2، Android SDK 35 و JDK 17 لازم است (هنگام استفاده از Android Studio نصب می‌شوند). مدل شناسایی بارکد `com.google.mlkit:barcode-scanning:17.3.0` به‌صورت Bundled داخل APK بسته‌بندی می‌شود؛ بنابراین بعد از نصب، برای خود اسکن نیاز به دانلود مدل نیست. برنامه برای جستجوی کالا و ثبت عملیات باید به Wi‑Fi مرکز و سرور متصل باشد.

برنامه با دوربین CameraX و مدل ML Kit بارکد را بدون لمس شاتر تشخیص می‌دهد و نتیجه را به سیستم مرکزی ارسال می‌کند. اتصال با Broadcast UDP به پورت ۸۷۶۶ کشف می‌شود و سرویس HTTPS روی پورت ۸۷۶۵ قرار دارد. اولین اعتماد TLS از نوع TOFU است؛ روی شبکه عمومی نصب/اعتماد اولیه انجام ندهید. ورود کاربر سامانه جداگانه لازم است.

تست Java این بسته فقط Syntax را بررسی کرده است. **کامپایل APK، تست Permission اندروید و آزمایش اسکن واقعی گوشی انجام نشده است.**
