# مجموعه یکپارچه پروژه‌های باستیان — Bastiyan Monorepo

این مخزن واحد محل نگهداری پروژه‌های موجود در حساب GitHub متصل است؛ **نسخه عملیاتی HIS از روی این مخزن تأیید نشده است.**

## سازمان‌دهی
- `apps/catalog/`: گردآورنده کالا و بارکد؛ فایل منبع v2.2 و ابزار ساخت واقعی اندروید و ویندوز
- `apps/his/`: مستندات HIS و یادداشت‌های سازگاری
- `apps/kiosk/`: محل آینده کد کیوسک؛ در زمان ممیزی این بخش در GitHub وجود نداشت
- `archive/his/`: بسته‌ها و یادداشت‌های قدیمی، حفظ‌شده برای ردیابی
- `.github/workflows/`: ساخت خودکار برنامه‌های مستقل، بدون استقرار خودکار روی Production
- `docs/`: گزارش تطبیق و راهنمای انتقال

## ملاحظه مهم در مورد فایل‌های ریشه
فایل‌های `index.html`، `portal.js`، `portal.css`، `server.js` و سایر اجزای قدیمی HIS
در ریشه **برای جلوگیری از شکستن مسیر احتمالی استقرار فعلی تغییر مکان داده نشده‌اند**.
وجود آن‌ها به معنی سالم یا به‌روز بودن این نسخه نیست؛ قبلاً نام نسخه‌های ناسازگار در همین فایل‌ها دیده شده است.

## وضعیت آخرین توسعه‌ها
- در بررسی اولیه شاخه `main` حاوی آرشیوهای HIS 5.0.1 و 5.1.0 بود؛ نسخه‌های R24/R25 هنوز در تاریخچه تأییدشده مخزن ثبت نشده بودند.
- کد ساخت گردآورنده v2.2 از شاخه `catalog-build-v22` به تاریخچه واحد `main` منتقل شد.
- ۳۴ فایل منبع قابل ویرایش تحت `apps/catalog/src/` قرار دارند و GitHub Actions از همین فایل‌ها برای ساخت استفاده می‌کند.
- کد کیوسک در این مخزن پیدا نشد؛ از فایل موجود نمی‌توان محتوای آن را بازسازی کرد.

برای توضیح دقیق به `docs/REPO_AUDIT_FA.md` و `docs/SECURITY_FA.md` مراجعه کنید.
